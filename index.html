Published • IEEE Xplore

MediGuard 7X — Smart, Secure Medicine Box

A smart, cost-conscious embedded medicine box designed to assist patients in following daily medication routines through scheduled reminders, biometric authentication, and automated compartment access control.

  • 7 dedicated medication compartments with servo-controlled solenoid locking
  • Biometric access control via R307 optical fingerprint sensor
  • DS3231 RTC module scheduling, 16×2 I²C LCD, RGB LEDs, and buzzer
  • Presented at ICIST 2025, ICST 2025 (Best Idea Award), & published on IEEE Xplore
Arduino Mega 2560 R307 Fingerprint DS3231 RTC Solenoid Lock Embedded C
IEEE Paper → Conference Details
Award Winner • 3rd Place

MediGuard 2.0 — Connected Box with App Monitoring

Final-year project upgrading the original concept to an ESP32-based architecture featuring an automated 6-compartment rotating tray, voice alerts, IR pickup sensing, and companion mobile application monitoring.

  • ESP32 DevKitC-32UE controller with mobile app scheduling and caregiver alerts
  • Motor-driven rotating tray powered by DRV8825 stepper motor driver
  • Voice alerts via DFPlayer, PAM8403 amplifier, and IR hand-detection pickup sensor
  • Secured 3rd Place in Think & Thrive technical paper competition (March 2026)

IoT Disaster Management

Smart Landslide Detection & Early Warning System

Real-time early warning system designed to improve safety in rainfall-prone and hilly regions. Evaluates soil water saturation and ground vibration against predefined thresholds to dispatch local and remote alerts.

  • Distributed dual-node ESP32 architecture communicating over Wi-Fi
  • Real-time threshold classification into Safe, Warning, and Emergency states
  • Remote emergency warning dispatch via Telegram Bot API + local sirens
  • Low power consumption design with scalable sensor node clustering

IEEE Xplore Publication

MediGuard 7X: A Smart, Secure Medicine Box for Timely Medication

Conference: 7th IEEE International Conference on Cybernetics, Cognition and Machine Learning Applications (ICCCMLA 2025)
Co-Authors: Anjali Ananthan, Anamika K, Muhammed Sahal N, Navya A P, Dr. Jayadevan R
